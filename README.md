# packcell

Pack CSV/TSV cell tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/packcell/

## Install / run

```bash
git clone https://github.com/theworker02/packcell.git
cd packcell
node src/cli.js
node --test
```
